# MT-PICS-Anonymous
MT-PICS: Multi-Trigger Poisoning of Code Large Language Models via Instruction Prefixes and Code Style

## Repository contents

- [Code editing](code_editing/) contains experiment and perplexity scripts, configuration, and dataset manifests.
- [Code completion](code_completion/) contains BEEAR defense scripts, offline metric comparison, and HumanEval workflows with the benchmark prompts.

The code-editing test CSVs and perplexity scoring inputs are included. Supply the training and validation CSVs separately using the file names and checksums in the experiment manifests. Model weights, adapters, and run outputs are kept outside this repository.
